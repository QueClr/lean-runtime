Status

State of 2026-10-04. main holds semantics, both io batches and both sched batches.

Merged on main

BatchWhat it added
semantics-1Hashing; Float and Float32 formatting and conversions; the libm functions; the fixed-width integers; the String position functions.
semantics-2The Nat and Int rules over the big-number traits; the array edge rules; the panic texts and exit statuses; the text of leaf values.
io-1The IO.Error mirror and its decoding; the FILE model; handles and the standard streams; the exit sequence. The file system, the environment, the clock, the debug primitives and the startup descriptors.
sched-1The scheduler: deferred tasks on corosensei contexts, the yield points, promises, Std.Sync's primitives and Lean's exit behaviour. docs/sched.md, with the proof of the glue's one unsafe step; the driver with a twin for every task and sync case; LB-13 and its cases.
io-2Child processes over posix_spawn, the environ copy, stream redirection, temporary files, timeit and Std.Time's clock, the UV.System queries. A Rust twin for each of its program cases; LB-14 to LB-17 and their cases.
semantics-3String.Pos.Raw.set, ByteArray.validateUTF8, the toolchain's build facts, and the text functions of IP addresses. The libm ports of cbrt, cbrtf, atanh and atanhf on every target.
sched-ioCooperative blocking IO: reads, writes, flock and waitpid let the other tasks run (details). The scheduler's event loop, and Std.Internal.UV's loop, timers and signals on it; the taskio/ and uvloop/ cases.
cases-xtProgram cases from lean2rr's cross-test of leanrs's fixtures, cases for LB-01, LB-02 and LB-03, and cases for two decisions (DV5, DV10).
cases-tasks-1Program cases for tasks and for two io findings, recorded natively; scripts/cases.py runs every case under a memory cap.

Each batch has its rows or program cases, and benchmark pairs: one per semantics function, and one per hot path of io (Testing). No timing session has run yet.
